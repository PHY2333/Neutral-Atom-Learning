# Neutral Atom Learning Index

## Main Roadmap

**📍 节点 1：二能级基础动力学与布洛赫进动**

- **核心内容**：有效哈密顿量 $\hat H_{\mathrm{eff}}$ 的建立，物理参数（Rabi 频率 $\Omega$、失谐 $\Delta$、相位 $\phi$）如何映射到布洛赫球的三维有效磁场 $\mathbf\Omega_{\mathrm{eff}}$。
    
- **物理图景**：横向项控制布居转移（转轴），纵向项控制相位积累（绕 Z 轴进动）。
    

**📍 节点 2：Rydberg 激发的子空间映射**

- **核心内容**：引入高激发态 $|r\rangle$。确立 $|1\rangle \leftrightarrow |r\rangle$ 为实际受驱的二能级子空间，而计算基态 $|0\rangle$ 为暗态/旁观态。
    
- **物理图景**：驱动场并未直接耦合 $|0\rangle \leftrightarrow |1\rangle$，这是理解后续为什么缺乏直接比特翻转（$X$ 错误）的前提。
    

**📍 节点 3：单比特视角的 $\pi$ 与 $2\pi$ 脉冲**

- **核心内容**：共振条件下，$\pi$ 脉冲实现布居完全转移，而 $2\pi$ 脉冲完成几何相位积累（$|1\rangle \rightarrow -|1\rangle$）。
    
- **物理图景**：在 $|1\rangle \leftrightarrow |r\rangle$ 空间的拉比振荡，投影回 $\{|0\rangle, |1\rangle\}$ 计算空间后，等效为一个纯粹的相位门（$Z$ 旋转）。
    

**📍 节点 4：双原子相互作用与 Rydberg 阻塞门 (Blockade)**

- **核心内容**：引入范德华相互作用项 $V_{rr} = C_6/R^6$。理解阻塞机制（$V_{rr} \gg \hbar\Omega$）下，三步脉冲序列如何条件性地阻止态的演化。
    
- **物理图景**：纠缠门的本质——让不同的双比特计算基态（$|00\rangle, |01\rangle, |10\rangle, |11\rangle$）在相空间经历不同的闭合或非闭合路径，从而积累出特定的相对相位。
    

**📍 节点 5：环境微扰与哈密顿量噪声项**

- **核心内容**：将真实的物理系统波动引入理想哈密顿量。写出微扰项 $\delta\Omega(t), \delta\Delta(t), \delta\phi(t), \delta V_{rr}(t)$ 以及非厄米的耗散项（Lindblad算符）。
    
- **物理图景**：区分引起能量偏移的对角微扰（失谐、光移、多普勒）与引起耦合变化的非对角微扰（振幅起伏）。
    

**📍 节点 6：物理噪声到线路错误的投影 (Error Channel Mapping)**

- **核心内容**：
    
    - **能级/相位偏移** $\rightarrow$ 随机动态相位 $\rightarrow$ $Z_1, Z_2, Z_1Z_2$ 错误。
        
    - **脉冲面积误差** $\rightarrow$ 过/欠翻转 $\rightarrow$ 布居数错误 / Leakage。
        
    - **有限寿命/非完美阻塞** $\rightarrow$ 自发辐射与残余激发 $\rightarrow$ 泄漏（Leakage）与非对称 Pauli 错误。
        
- **物理图景**：用对角矩阵的微小随机相因子，推导出以 $Z$ 为主的误差通道。
    

**📍 节点 7：Rydberg 平台 Z-Biased 特性的根本来源**

- **核心内容**：综合以上分析，论证为什么宏观上的低频环境噪声（磁场漂移、激光散斑、原子热运动）主导了系统的退相干，且极难产生共振的 $X$ 型比特翻转。
    
- **物理图景**：建立“物理层低频对角微扰”与“逻辑层高度偏置噪声”之间的必然联系。
