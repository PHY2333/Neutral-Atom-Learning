从 |0⟩ 出发，取旋转轴 n = +y，脉冲面积 α = π/2。 这对应单比特旋转 Ry(π/2)，把 Bloch 向量从北极转到 +x 方向，因此 |0⟩ → |+⟩ = (|0⟩+|1⟩)/√2。严格的 Hadamard 与 Ry(π/2) 只差一个可由 virtual Z 修正的相位约定。
